REAL ARCHITECTURE (how it actually works)
================================================================================

  Telegram user
      |
      v
  OpenClaw Gateway (Docker, port 18789/18790)
      |
      |-- Receives chat commands (!status, !positions, etc.)
      |-- Uses bridge-logic.js for custom AI behaviour
      |-- Forwards specific commands → MooPredict server (port 3001/webhook)
      |
  MooPredict Server (port 3001)
      |
      |-- Receives webhook from OpenClaw, processes commands
      |-- Scrapes news every hour, posts alerts → OpenClaw (port 18789)
      |-- Scrapes X posts every 15 min, posts alerts → OpenClaw (port 18789)
      |-- Connects to Moomoo (port 11111) for positions + trade execution
      |
  Moomoo (moomoo_openD, port 11111)
      |
      -- Paper trading account, place buy/sell orders

  Two-way communication:
    MooPredict → OpenClaw  :  POST http://127.0.0.1:18789/webhook  (news alerts)
    OpenClaw   → MooPredict:  POST http://host.docker.internal:3001/webhook (commands)

server/services/newsScraper.ts
  - Fetches BBC, Reuters, CNBC, MarketWatch, Google News via RSS
  - 10 articles per source max (50 total)
  - Deduplicates against news_intel DB table
  - Sends new headlines batch to OpenClaw in one clean message
  - No Ollama, no AI. Just raw headlines.

server/services/xScraper.ts
  - Fetches Nitter RSS for: elonmusk, realDonaldTrump, federalreserve,
    GaryGensler, SECGov
  - Nitter public instances (free, no API key needed):
      Primary:  https://nitter.net/{user}/rss
      Fallback: https://nitter.privacydev.net/{user}/rss
  - Deduplicates against x_posts DB table by post URL
  - Any new post → immediate alert to OpenClaw (tweets are time sensitive)
  - If all Nitter instances fail for a user, silently skip (log warning only)

server/services/futuService.ts  (NEW simplified version)
  - Connects to moomoo_openD on port 11111
  - getPositions()  → list of open positions with qty, avg price, current P&L
  - getBalance()    → available cash, total portfolio value
  - placeOrder(symbol, side, qty, price)  → execute buy/sell
  - reconnect()     → manual reconnect if connection drops

server/services/cron.ts
  - Two jobs only:
      Every 60 min  → newsScraper.run()
      Every 15 min  → xScraper.run()
  - Both run 24/7, no market hour checks, no weekend logic

server.ts  (new clean version)
  - Express on port 3001
  - Routes:
      GET  /health                       → { ok: true, uptime }
      GET  /api/notifications/pending    → for notify-poller.mjs

      POST /webhook                      → receives commands from OpenClaw

      !checkstatus  → fetch positions + P&L from Moomoo, send to Telegram

ABOUT bridge-logic.js
================================================================================

OpenClaw Docker mounts this file:
  /Users/admin/moopredict-ai/bridge-logic.js → /app/bridge-logic.js (read-only)

On startup it patches the file into OpenClaw's main JS bundle:
  sed ... '/async function getReplyFromConfig(ctx, opts, configOverride) {/r /app/bridge-logic.js'

This means:
  - The file MUST exist before starting OpenClaw Docker
  - If the file has a syntax error, OpenClaw's AI replies will break
  - If the file is empty, the patch inserts nothing (safe fallback)

Current status: bridge-logic.js was deleted from the repo.
Fix: recreate it with the correct custom logic, or with an empty comment as
     a safe placeholder until you decide what you want OpenClaw to do.
